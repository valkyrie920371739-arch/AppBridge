从一个应用开始

  1. 1

    添加你的应用

    选择 Windows 程序或安装包。TyranoScript 游戏可选择完整文件夹导入。

  2. 2

    测试 Windows 运行环境

    在“运行环境”中自动检测内置 Wine，再点击“测试 Windows 启动”。首次初始化可能需要约一分钟。原生加载入口无需 Wine。

  3. 3

    打开应用，查看实际结果

    安装包完成安装后，可在应用菜单中“更改启动程序”，继续使用同一个运行目录。遇到异常时，可查看应用数据中的运行日志或导出诊断日志。

关于这个测试版本

运行组件随软件包提供。每个应用的兼容情况以实际运行结果为准。

软件包与工程保存在云盘；AppBridge 可管理的运行组件、缓存、日志与 Windows 应用数据集中在本机工作区。进入“文件与数据”即可查看。

目录内程序直接使用；外部程序确认后复制完整文件夹，源文件保留。TyranoScript 游戏会复制到库中，旧存档不会自动迁移。

“移出资料库”保留文件与数据。每个应用有独立的运行目录，但这不是限制文件访问的安全隔离环境。

应用及游戏资源归各自作者所有。
